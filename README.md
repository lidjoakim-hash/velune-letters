# Velune Letters

Digital wedding invitations with a wax-seal opening, by Velune Weddings.

- Couples design in the **studio**, add guests, send personal links, follow replies and pay with Stripe.
- Guests open the invitation, see a countdown, schedule, map, photos and reply (EN / RO / NO).
- You see revenue and every couple in **admin**, and can gift plans.

Plain HTML + JavaScript, no build step. Backend: Supabase (database, login, photos, payments functions).
Runs in demo mode until you add keys in `assets/config.js`.

Start with **SETUP.md**.
